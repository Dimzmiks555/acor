# ACOR NUTRITION

Static Russian-language product landing page. No dependencies or build step.

## Preview

`python3 -m http.server 4350 --bind 127.0.0.1`

Open http://127.0.0.1:4350/ .

## Publishing

Publish the repository root on the existing Netlify project `acornutririon`.
The original repository is `RazmahDM/acor`; the currently authenticated account has read-only access. No production change has been made by this redesign.

Product photos, package details, review excerpts and the Ozon destination were preserved from the existing website. The hero image was generated using the existing ACOR packaging as reference. The original static product images remain the source for specifications. Bootstrap Icons are licensed under MIT (see img/icons/LICENSE).

All purchase links lead to the existing shared Ozon destination; no individual product listing URLs or live prices were supplied. Update those links if separate listing URLs become available.
